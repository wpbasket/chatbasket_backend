# Public Utils

This directory is reserved for public domain-specific utility functions.

## Purpose

Place utility functions here that are:
- Used **only** by the public domain (public handlers/services)
- Not shared with other domains (personal, etc.)

## Common Utilities

For utilities shared across multiple domains, use the base `utils/` directory instead.

## Examples

Public-specific utilities might include:
- Public user validation helpers
- Public domain-specific formatters
- Helper functions for public-only features
